💡 How to configure Gmail SMTP (100% Free)
  1. Set SMTP Host to smtp.gmail.com and Port to 465 (Check Use SSL)
  2. Go to your Google Account Security page
  3. Enable 2-Step Verification if not already enabled
  4. Search for App Passwords, create one (e.g. "AI Lead Agent")
  5. Copy the 16-digit password generated and paste it as your App Password below
